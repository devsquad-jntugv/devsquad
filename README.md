# Yukta DevSquad 🚀

Official portal for **Yukta DevSquad**, the premier technical club hub of the Department of Information Technology at **Jawaharlal Nehru Technological University Gurajada, Vizianagaram (JNTU-GV)**.

---

## 🌟 About DevSquad

Yukta DevSquad fosters a community of innovation, technology, and collaboration among students across diverse sub-clubs and student chapters:
* 🤖 **AI/ML Club** – Exploring machine learning, data science, and AI tools.
* ⚡ **EI Society** – Emerging and innovative technical domains.
* 🌐 **FST (Full Stack Tech)** – Web development, backend systems, and frameworks.
* 📚 **GATE Gurukul** – Technical preparation and guidance for GATE and competitive exams.
* 🎨 **Arts Club** – Creative media, design, and cultural activities.
* 🤝 **SEVA Club** – Social impact, outreach, and community drives.
* 👩‍💻 **Nyan Club** – Empowering women in technology and engineering.
* 📢 **Broadcast Club** – Media, announcements, public relations, and event coverage.

## 🛠️ Tech Stack

* **Frontend:** React 18, Tailwind CSS, Chart.js, React Router, React Icons
* **Backend:** Node.js, Express.js, MongoDB, Mongoose
* **Deployment:** Vercel

## 🚀 Getting Started

### Prerequisites
* [Node.js](https://nodejs.org/) (v20+ / v22+ / v24+)
* [npm](https://www.npmjs.com/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/devsquad-jntugv/devsquad.git
   cd devsquad
   ```

2. **Install dependencies:**
   ```bash
   # Root dependencies
   npm install

   # Backend dependencies
   cd backend && npm install && cd ..

   # Frontend dependencies
   cd frontend && npm install && cd ..
   ```

3. **Run the development servers:**
   ```bash
   # Runs both frontend and backend concurrently
   npm start
   ```

   Alternatively, run them separately:
   * **Backend:** `cd backend && npm start` (Runs on `http://localhost:5000`)
   * **Frontend:** `cd frontend && npm start` (Runs on `http://localhost:3000`)
